# Bundled mod search aliases

`pocketj-mod-aliases.json` includes Chinese mod names and aliases derived from
[ModLangForge](https://github.com/MrPippi/ModLangForge), data snapshot
`588a3e59fc3162c87590f5d785be93e71a838fb4` (upstream `data/` license applies).
The upstream dataset is licensed under **CC BY-SA 4.0** except where an
individual `mod.json` declares another license. Entries with a
non-commercial license were excluded. The bundled subset contains only mod
display names and Chinese aliases; it does not include mod translation files
or game assets.
