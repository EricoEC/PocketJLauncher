## Automated coverage

Namespace migration details and the exact retained-legacy allowlist are in
`RENAME_v1.5.md`. After building, also run
`node Tests/rename-tests.mjs --app /tmp/PocketJ-v15-DerivedData/Build/Products/Release-iphoneos/PocketJLauncher.app`
to verify the generated Java bindings and native exports in the actual app.

- JAR install, invalid replacement, disk/metadata failure rollback, stable mod ID,
  disabled-state preservation, permanent deletion and symlink exclusion.
- A deleted/recreated same-name instance gets a new UUID.
- SHA mismatch/HTML archive rejection, streaming hashes, local Chinese search,
  extensible CSV parsing/import and unknown-query preservation.
- Modrinth/CurseForge version mapping, CF page 2, MC/loader separation, required
  and optional dependency planning, and dependency-first ordering (mock API).
- Same-name local/Microsoft/Yggdrasil identities, server+UUID scoping and HTTPS
  address normalization.
- Six mirrored environment aliases, canonical-key precedence in either custom
  input order, absent/empty values, all eleven typed render ABI forwarders,
  Java/JNI/GLFW source names and five legacy Makefile override fallbacks.
- Fabric Loader version versus Minecraft version, including snapshot suffixes.
- Both TouchController JNI signatures, handshake, bounded queues and releases
  with a fake JNI function table; not an actual Minecraft/mod execution.
- Release build checks `_main` on the native executable actually embedded in
  the app, rather than on Xcode's temporary host wrapper.
- Control-page footer delegates are executed in a Foundation fixture across
  repeated touch/gamepad mode switches: inactive sections return no text, and
  actual/estimated heights agree. This does not emulate UIKit rendering.
- Startup-stage tests cover monotonic callbacks, real first-frame signals,
  stale-session rejection, termination and concurrency. A source contract test
  compares startup/log Chinese and English strings with Vision v0.2, with the
  explicit iOS-only `engine.stage.jvm` PocketJ-brand override,
  plus content order, SF Symbols, 12-point spacing and 24-point padding. These
  checks do not establish pixel-identical system chrome or real GPU presentation.

The Foundation harness cannot link the project's iOS-only UnzipKit binary. Its
archive fixture uses a ZIP signature for file-transaction tests; actual archive
listing, CRC/extraction and UIKit behavior require the device checklist below.

## Required device checks before release

1. iOS 14 phone + current iOS phone + iPad: long labels, larger fonts, landscape,
   version sheets, swipe actions, batch selection, Files/iCloud and share sheets.
   On the Control tab, switch touch/gamepad repeatedly, scroll to both ends and
   rotate; the touch explanation must never cover the mode selector or appear
   in gamepad mode. Repeat in Chinese/English and with larger text.
2. Known-good 1.1/1.2.1, 1.21.11, 26.2 and 26.3 instances; Java 8/17/21/25.
   Verify the reported Java 25 entry-point failure no longer occurs.
   Before the first frame, compare the centered black startup layer with Vision
   v0.2: spinner, stage, monospaced timer, live log and export actions. Test the
   actual Metal/GL/Vulkan and software presentation paths; the overlay must
   disappear on the first frame and never return over gameplay. Force a failed
   launch, open/close logs and share on iPad; rotation and larger text must fit.
3. Import a real Fabric/Forge/NeoForge/Quilt JAR. Rename, annotate, export,
   disable, update and change back to an older version. No old JAR remains after
   success; an invalid download must leave the original working JAR intact.
4. Modrinth + CF-only mod: identification, per-mod and batch update checks,
   update lock, required dependencies, optional dependencies, root-only install,
   source refusal, interruption/pause/resume, and malformed/no-network responses.
5. Online MR/CF modpack: registration performs no package download; launch page
   downloads it and configures its loader. Repeat with local mrpack/CF ZIP,
   a wrapped-root ZIP and Prism/MultiMC import. Retry a cancelled package.
6. Export/import each advertised format; manually inspect manifest file IDs,
   URLs/size/hash, game/loader versions and overrides. No launcher account,
   pairing file, provisioning/signing data or cached build output may be present.
7. Shader/resource/data-pack history selection, worlds import/export and a ZIP
   with no/multiple `level.dat`. Never overwrite a different same-name world.
8. LittleSkin and a custom HTTPS Yggdrasil server: multiple profiles, refresh,
   cached offline identity/avatar, same-name account coexistence and deletion.
   Redirecting credential POSTs to another origin must fail rather than forward.
9. TouchController native mode: test the actual old/new compatible mods, pointer
   movement/release, keyboard request, leaving a world and rotating the device.
   UDP mode requires the matching mod implementation. Ordinary instances default
   to off and must retain their existing controls unchanged.
10. A nonzero game exit shows local diagnostic hints plus the original log and
    feedback buttons. Normal exit must not be presented as a crash.

## Explicit limitations / not shipped as completed

- The core Minecraft downloader still uses the established native implementation;
  add-ons share the new verified client. All modpacks use the launch-page entry.
  A complete transport migration and user-configurable mirror policy remain a
  separate step; the new client supports candidate URLs and finite retries.
- Dependency planning follows provider version IDs and game/loader metadata; it
  is not a complete solver for every arbitrary version constraint in every JAR.
- Chinese search has bundled aliases, user aliases and CSV expansion, not an
  unlicensed full third-party dataset or an AI/network translation service.
- Real authentication, download-provider authorization and actual TouchController
  mod behavior are not proven by mocked tests or `BUILD SUCCEEDED`.
- No FSR, AI, plugin framework, virtual LAN or automatic renderer blacklist.
- No IPA/TIPA release, public push or tag is generated until device acceptance.
